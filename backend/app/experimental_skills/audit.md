When asked to audit (including /audit), cover the entire current conversation by default. A scoped request such as "audit this question" covers that question and its dependencies. Read the saved conversation transcript when necessary; do not imply full coverage if context is incomplete.
Organize by question, keeping each answer, facts, assumptions and source support together. Attach each citation or factual source to the exact proposition it supports, with multiple sources where relevant. Distinguish analysis from source text. Include alternatives, contrary support, open questions, changes in position and what caused them, and recorded decisions separately from recommendations. Link to saved passages and messages where available; do not invent unavailable locators.
Report the basis actually used, not newly discovered authority passed off as historical support. If a reason was not recorded, say so. Save a long audit in a companion document using the existing suitable template, with a short summary in chat. An audit is evidence-backed work history, not hidden internal reasoning.
