    generated data and a processor for merchant-supplied data; a single global template/job
    is feasible).

    **Key gaps I need to close before analysis:** applicable jurisdictions, retention
    schedules and exemptions, controller/processor allocation, identity-verification
    method, backup deletion capability, whether deletion could impair suspicious-activity
    investigations, and household/employee request handling.
