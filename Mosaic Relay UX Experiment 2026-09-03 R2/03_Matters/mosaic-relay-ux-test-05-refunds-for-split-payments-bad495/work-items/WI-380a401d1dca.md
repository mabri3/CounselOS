# Specify ledger controls for negative seller balances and held payouts

Design the ledger controls implementing the recorded decisions: negative seller balances allowed with future payouts held until recovered; immutable order ledger with versioned allocation snapshot at capture as source of truth; every refund and chargeback appends an auditable event; dispute adjustments only via approved reconciliation record; customer-support overrides only with a named approver. Define the exception-approval workflow and audit trail.
