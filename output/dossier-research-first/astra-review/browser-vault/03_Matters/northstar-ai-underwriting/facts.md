# Facts

## Confirmed from supplied materials

- Northstar v3 would affect requested and system-initiated credit-line decisions.
- The population includes sole proprietors and other small-business cardholders.
- The model uses about 180 derived features from cash flow, account behavior, repayment history, and device activity.
- The model team can produce local feature-importance output for each decision.
- Operations currently selects notice reasons after file review.
- Product proposes automated mapping from model features to twelve customer-facing reasons.
- The current validation deck does not include proxy-group outcome testing or a less-discriminatory-alternative analysis.
- Device data was first collected for fraud and account-security purposes.
