# Legal AI Reddit evidence set

This directory contains raw, structured Reddit source records for the CounselOS market-research update. `prior-20-sources.jsonl` is the source list from the first two research waves. The `luna-*.jsonl` files are new discovery passes.

Each line is one source record. A record is not automatically a verified product fact. The synthesis must distinguish firsthand reports, stated team size, direct trials, hearsay, vendor claims, and general opinion.
