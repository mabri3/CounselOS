Attack these failures:

- Current answer or issue source marker uses another output revision's claim applicability or a different passage from the same source. Chat source links disappear after reload. A draft link retargets actions to a source.

- Unsupported claims appear supported because a generic source name matches. Actor, jurisdiction, fact/assumption explanation is absent or attached to a different claim.
- A fact answer or completed work resolves an issue, accepts a recommendation, or closes the matter. Risk acceptance avoids the existing recorded-decision action. Cancel/open writes a disposition. Retry duplicates work or dispositions. A stale revision overwrites a newer record.
- Scenario Analyze changes real facts or decisions. Late/failing analysis overwrites a newer run. Scenario Save creates a duplicate rather than retaining the current baseline. Adopt applies more than the reviewed selected change.
- Discuss below the header loses unsent text or starts another conversation. Map return loses selected issue or drafts. Source return loses focus/origin. Keyboard cannot reach equivalent canvas actions.
- Opening two documents uses one local edit slot, a late load replaces another file, recovered edits silently rebase, or preview focus changes the submitted rewrite/export target. Historical/final paths resolve to current content. Sources/finals appear editable without an explicit supported successor.
- Priority drops unranked/no-support issues or counts revisions as products. Unknown/historical/hypothetical map state is hidden or rendered as an active/legal outcome. Shared questions/cycles/missing records disappear.
