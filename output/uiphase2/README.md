The PNGs in `designs/` are generated proposals. The PNGs in `screenshots/` show the live app. Do not treat generated dates, people, decisions, sources, status counts, or company details as real records.

The designs follow the current A-style amendment: white and cool neutral surfaces, serif headings, dark ink navigation, navy primary actions, and purple agent work. Some small raster details still differ from the design rules. The verification report lists the corrections that implementation must apply.

No application code, provider settings, schedules, or vault records were changed. This delivery does not implement the UI.

`manifest.json` identifies the selected image files. `reports/generation-provenance.json` contains the generation and correction prompts. `coverage.json` maps each screen to observed or source-derived coverage.
