The mock proves UI, persistence and routing. It does not prove external model quality. Real provider failure remained visible. Earlier false-dirty, missing preview recovery, incorrect preview view, duplicated caveats, clipped table text, and narrow-page sizing faults were reproduced and corrected. The fresh reviewer also checked source and reference images. The visual matrix records measured differences rather than claiming pixel identity.
