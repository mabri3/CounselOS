# Original Request

Harborline wants to add a “Money Insights” feature that categorizes transactions, predicts recurring bills, alerts customers to unusual spending, and suggests Harborline products based on account activity. Harborline would send transaction descriptions, amounts, merchant data, account metadata, and device identifiers to a cloud analytics vendor. Models would generate categories and recommendations for consumer and small-business users. Product wants insights enabled by default, with controls for marketing personalization in settings. The planned launch is in five months. We know the vendor will process data in the United States and contractually may not sell it. We have not decided how long model inputs and outputs will be retained, whether vendor staff may review data for quality, whether data can train shared models, or how business-account data relating to employees and customers will be treated.

Please advise which uses are permitted under financial privacy, state privacy, banking confidentiality, and unfair-practices rules, and which require opt-in consent or an opt-out. We need a decision on whether service insights and product marketing must be separated, what the initial setting should be, and what disclosures must appear in onboarding, the privacy notice, and feature settings. Please also define limits on vendor use, model training, retention, deletion, and access rights. Explain how Harborline should respond if a customer disables personalization but still needs transaction categorization for core account functions.
