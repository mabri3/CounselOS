# # State notice requirements — lawyer response

The current work item names CA, CO, GA, IL, NY, TX, and WA as a review list. I will not treat that list as the final launch list. The longer-term installment product may have a different set of states and may have different creditor, licensing, and notice rules.

For each product and state, Compliance should verify whether state credit, lending, or credit-reporting law adds content, timing, delivery, language, licensing, or recordkeeping requirements. The output should be a state matrix tied to the creditor, decision type, report use, notice template, deadline, and delivery channel. Keep the federal baseline and state additions visibly separate.

Status: unverified lead. Missing facts: final state list, product classification, creditor by state, and current official state authorities. Required evidence: approved state matrix, source links or citations, template overlays, and sign-off owner. Do not enable a state flag until the matrix is complete.
